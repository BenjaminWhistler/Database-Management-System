# Database Management System
This project is a combination of a C# .NET WinForms application and Microsoft Access database in order to create a database management system. I completed this project for my System Support Class at College of the Albemarle.

The system includes the ability to add, edit, delete, filter and view relationships for records, alongside other features like lookup functionality and the ability to open multiple windows which update in real time.
